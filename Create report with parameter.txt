1. edit the data model
2. click the data set  and edit
3. use this query
select	 "- Invoice Accounting"."SLA Unrounded Entered Amount Credit" as "SLA Unrounded Entered Amount Credit",
	 "- Invoice Accounting"."SLA Unrounded Entered Amount Debit" as "SLA Unrounded Entered Amount Debit",
	 "- Invoice Accounting"."Ledger Currency Name" as "Ledger Currency Name",
	 "- Invoice Accounting"."Ledger Currency" as "Ledger Currency",
	 "- Invoice Accounting"."Invoice Currency" as "Invoice Currency",
	 "- Invoice Accounting"."Invoice Currency Name" as "Invoice Currency Name"
 from	"Payables Invoices - Transactions Real Time"."- Invoice Accounting" "- Invoice Accounting" WHERE  "- Invoice Accounting"."Ledger Currency Name" = :CURR
<save>
4. go to data tab an type parameter value
	curr: Euro
	<view>
5. run the report and see the output
